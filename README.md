# Warriors of the End

Warriors of the End is a Fabric mod for Minecraft 1.21.11 that adds diamond-like armor and netherite-tier weapons. This mod introduces the Enderite Armor Set and Enderite Weapons, providing enhanced protection and combat capabilities for players.

## Install

1. Install Fabric Loader 0.14.0 or later.
2. Install Fabric API.
3. Download the mod jar file from the [releases page](https://github.com/yourusername/warriors_of_the_end/releases).
4. Place the jar file in the `mods` folder of your Minecraft instance.

## Use

1. Craft the Enderite Armor and Weapons using Ender Pearls as the repair material.
2. Equip the armor for enhanced protection and wear resistance.
3. Use the weapons for powerful attacks in combat.
